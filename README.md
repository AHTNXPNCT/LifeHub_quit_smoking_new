# LifeHub: Брось курить

«Бросай никотин и живи. Один день за другим.»

LifeHub — русскоязычное PWA-приложение для личной программы отказа от никотина.
Оно работает без регистрации: данные дневников, прогресса и настроек хранятся
на устройстве пользователя в IndexedDB.

## В этом выпуске

- 365 уникальных дней программы с ограничением: нельзя завершить несколько
  дней подряд в одну календарную дату устройства;
- счётчик без никотина, экономия, XP, уровни, достижения и интерактивный лес;
- дневники тяги, настроения, CBT и срывов;
- раздел «Хочу курить», календарь, игры, библиотека, помощь и настройки;
- автономная работа PWA и Service Worker;
- исправленное сохранение всех записей дневника;
- понятный ввод «Количество сигарет в день, шт.» и «Стоимость пачки» без
  добавления стартового нуля к вводимому числу.

## Публикация и обновления

Проект предназначен для **обновления существующего Cloudflare Worker**
`lifehub-quit-smoking-new` через GitHub-репозиторий
`AHTNXPNCT/LifeHub_quit_smoking_new`.

Подробные пошаговые действия — в
[DEPLOY-CLOUDFLARE.md](./DEPLOY-CLOUDFLARE.md).

Важно: это не Cloudflare Pages. Не создавайте новый Worker и не используйте
другой адрес. После единовременного подключения GitHub в разделе
**Settings → Builds** каждый коммит в ветку `main` обновляет текущий Worker.

## Локальная разработка

Нужны Node.js 22 и pnpm 10.

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

Полная проверка:

```bash
pnpm run check
```

## Сохранность данных

При публикации новой версии данные существующих пользователей не стираются:
они находятся в браузере пользователя. Перед переходом на другое устройство
пользователь может использовать **Настройки → Экспорт JSON**, а затем
**Настройки → Импорт JSON**.

Информация о здоровье в приложении носит образовательный характер и не
заменяет консультацию медицинского специалиста.
