# LifeHub: Брось курить

«Бросай никотин и живи. Один день за другим.»

LifeHub — автономное русскоязычное PWA-приложение для личной программы отказа от никотина. Все данные сохраняются только на устройстве пользователя в IndexedDB: приложение не требует регистрации, сервера или аккаунта.

## Что реализовано

- программа на 365 уникальных дней с ограничением: можно завершить только один день за календарную дату устройства;
- счётчик времени без никотина, сигарет, пачек и экономии;
- интерактивный лес, серия, XP, уровни и достижения;
- экстренный сценарий «Хочу курить», дневники тяги, настроения, CBT и срывов;
- календарь активности, здоровье, статистика и экспорт данных;
- восемь офлайн-игр с 50 уровнями каждая;
- семь контрастных тем, доступность, уменьшение анимации и PWA-офлайн режим.

## Единственный способ публикации

Этот проект предназначен для **GitHub → Cloudflare Pages**. Он является обычным статическим Vite-приложением: Worker, Wrangler, сервер, переменные окружения и `NEXT_PUBLIC_SITE_URL` не используются.

Подробная инструкция — в [DEPLOY-CLOUDFLARE.md](./DEPLOY-CLOUDFLARE.md).

Коротко:

1. Загрузите содержимое архива `lifehub-github-cloudflare-source.zip` в новый репозиторий GitHub.
2. В Cloudflare выберите именно **Pages → Import an existing Git repository**.
3. Укажите `main`, `pnpm run build` и `dist`.
4. Дождитесь статуса **Success** и откройте выданный адрес `pages.dev`.

## Локальная разработка

Требуется Node.js 22 и pnpm 10.

```bash
pnpm install --frozen-lockfile
pnpm run dev
```

Проверка выпуска:

```bash
pnpm run check
```

## Хранение данных

История хранится в IndexedDB браузера. Перед сменой устройства используйте в приложении: **Настройки → Экспорт JSON**, затем на новом устройстве — **Настройки → Импорт JSON**.

Информация о здоровье носит образовательный характер и не заменяет консультацию медицинского специалиста.
