# Обновление существующего LifeHub в Cloudflare

Эта инструкция **обновляет уже работающий Cloudflare Worker**
`lifehub-quit-smoking-new`. Новый проект и новый адрес создавать не нужно.

## Перед началом

В приложении данные пользователей хранятся локально в браузере (IndexedDB).
Публикация новой версии не удаляет дневники, прогресс, настройки и данные
пользователей на их устройствах.

## 1. Связать существующий Worker с GitHub — один раз

1. Откройте [Cloudflare Dashboard](https://dash.cloudflare.com).
2. Откройте **Workers & Pages** → **lifehub-quit-smoking-new**.
3. В верхнем меню нажмите **Settings** → **Builds**.
4. В блоке **Git Repository** нажмите **Connect**.
5. Выберите GitHub и репозиторий `AHTNXPNCT/LifeHub_quit_smoking_new`.
6. В настройках сборки укажите:

   | Поле | Значение |
   | --- | --- |
   | Production branch | `main` |
   | Root directory | оставить пустым |
   | Build command | `pnpm run build` |
   | Deploy command | `pnpm run deploy` |

7. Не добавляйте переменные окружения.
8. Нажмите кнопку сохранения / подключения.

После этого Cloudflare будет автоматически собирать и публиковать новую версию
только при новом коммите в ветке `main`.

## 2. Загрузить обновлённые исходники в существующий GitHub-репозиторий

1. Скачайте архив `lifehub-worker-update-v1.3.3.zip` и распакуйте его.
2. Откройте репозиторий `AHTNXPNCT/LifeHub_quit_smoking_new` на GitHub.
3. Нажмите **Add file** → **Upload files**.
4. Откройте распакованную папку и выделите **содержимое** папки: файлы
   `package.json`, `wrangler.jsonc`, `index.html` и папки `src`, `public`,
   `.github`, `scripts`, `tests`.
5. Перетащите это содержимое в окно GitHub. Не загружайте ZIP-архив целиком.
6. Внизу нажмите **Commit changes** в ветку `main`.

## 3. Проверить обновление

1. Вернитесь в Cloudflare → **Workers & Pages** →
   **lifehub-quit-smoking-new** → **Deployments**.
2. Появится новая автоматическая сборка. Дождитесь статуса **Success**.
3. Нажмите **Visit** и откройте привычный адрес приложения.
4. При первом открытии после обновления обновите страницу один раз сочетанием
   `Ctrl + F5` (на телефоне — закройте приложение и откройте снова).

Не используйте кнопку **New deployment** для обновлений из GitHub: после
подключения репозитория новый коммит запускает корректное обновление сам.

## Что уже проверено в этой версии

- дневники тяги, настроения, CBT и срывов сохраняют записи;
- поля «Количество сигарет в день, шт.» и «Стоимость пачки» корректно очищают
  стартовый ноль при первом вводе;
- production-сборка, TypeScript, ESLint, тесты и пробное развёртывание Worker;
- маршруты PWA обслуживаются как одно приложение, включая прямое открытие
  разделов.
